# hushlip.shop

Source for the HushLip website, a single static page served with GitHub Pages at https://hushlip.shop/.

- `index.html` — the page
- `assets/styles.css` — styles
- `assets/fonts/` — Cormorant Garamond and Jost (SIL Open Font License 1.1, licence texts included)
- `CNAME` — custom domain for GitHub Pages
